# Bien démarrer sur Realms Reforged

**Realms Reforged** enrichit les villages, l'exploration, le combat, les compagnons et l'artisanat : quatre variantes de golems, Illageois guérissables, professions, boss, contrats et plus de 70 enchantements.

1. Installe **Minecraft Java 26.1 à 26.3**, **Fabric Loader 0.19.5+**, la **Fabric API correspondante** et **Java 25+**.
2. Place **un seul** JAR `golems-materiaux-1.13.1-mc26.1-26.3-fabric.jar` dans `mods`. Les cinq modules de version sont déjà dedans.
3. Sur serveur, mets Fabric API et le mod côté serveur **et client** pour les textures intégrées.
4. Sauvegarde ton monde et retire l'ancien datapack Golems si tu passes de sa version ZIP au mod.
5. Explore un village : les golems naturels varient selon le nombre de villageois voisins. Construire un golem vanilla à la main ne force pas ces variantes.
6. Progression conseillée : trouve un Illageois à soigner, découvre ses échanges, équipe tes alliés, puis lance des contrats de chasse en difficulté autre que Paisible.

## Questions fréquentes

**Dois-je installer cinq JAR ?** Non, un seul fichier externe.

**Les golems or/diamant ont-ils des œufs d'apparition spéciaux ?** Non : leurs variantes de base sont des golems de fer avec un système de tags et de rendu.

**Tous les enchantements sont-ils de niveau I ?** Oui, dans les données du JAR 1.13.1.

**Les recettes fonctionnent-elles toutes avec JEI/REI ?** Elles sont déclarées dans le JAR, mais l'intégration aux interfaces de recettes tierces n'a pas été testée.

**Cette version est-elle déjà en ligne sur CurseForge ?** Le JAR analysé est la version 1.13.1 fournie ici ; la page publique consultée indique encore des fichiers 1.13.0.
