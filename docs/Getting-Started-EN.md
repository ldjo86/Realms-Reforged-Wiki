# Getting started with Realms Reforged

**Realms Reforged** expands villagers, adventure, combat, companions and crafting: four material golems, curable Illagers, professions, bosses, bounty contracts and over 70 custom enchantments.

1. Choose the correct **JAR family for your Minecraft version**: **1.21–1.21.11** or **26.1–26.3**. They are separate distributions; [compare build-specific requirements](Installation-Compatibility.md).
2. Place only **one** JAR in `mods`. The **audited 1.13.1 / 26.x JAR** declares Fabric Loader 0.19.5+, matching Fabric API and Java 25+. Requirements for a **1.21.x JAR** need inspection of that separate file; the five 26.x modules are already embedded in the 26.x distribution.
3. Multiplayer needs the mod and Fabric API on server and clients for the integrated visual features.
4. Back up your world and remove the old Golems datapack ZIP if migrating.
5. Explore villages: natural iron golems may receive a material variant based on nearby villagers. Manually built vanilla iron golems are not automatically converted by this feature.
6. Try curing an Illager, assigning an ally, buying new items, and finally starting Bounty Hunter contracts outside Peaceful mode.

## Common questions

**Do I need to install five JARs?** No, install the single outer JAR.

**Do the material golems have unique spawn eggs?** The base material variants are tagged `minecraft:iron_golem` entities, not four separately registered new mobs.

**Are the 72 enchantments all level I?** Yes, in the 1.13.1 JAR data.

**Is 1.13.1 already listed for download on CurseForge?** The supplied JAR is 1.13.1; the public listing consulted for this audit still shows 1.13.0.
